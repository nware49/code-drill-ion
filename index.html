The daily drill

Drill below the autocomplete.

Seven prompts. Thirty seconds each. Name anything that fits. The answer everyone gives is worth 10 points. The one only you would think of is worth 100.

  1. Type any valid answer. Wrong guesses only cost time. Case, punctuation and small typos don’t matter.
  2. Rarer answers drill deeper. Each answer sits in a layer of the stack, from autocomplete down to ring −3.
  3. Every answer works once per drill. Use one twice and you get a use-after-free.
  4. The seventh prompt is root. It has exactly one right answer, worth 100. Hope you didn’t spend it earlier.

Why this exists

A language model is built to produce the most probable next token. Ask one to name a sorting algorithm and you’ll hear quicksort, every time. That’s the autocomplete layer, and here it’s worth 10 points.

Everything below it comes from somewhere else: the outage you were paged for, the RFC you read for fun, the man page you actually finished, the codebase you inherited and came to understand. That knowledge still matters. It’s how you tell when generated code is wrong, and it’s what this game scores.

Answers are checked against a hand-built bank, and every answer carries a line of history. Rarity is editorial: ranked by hand by how unlikely an engineer, or a model, would be to say it first.

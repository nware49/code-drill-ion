How a drill works

  1. Type any valid answer. Wrong guesses only cost time. Case, punctuation and small typos don’t matter.
  2. Rarer answers drill deeper. Every answer sits in a layer of the Earth, from topsoil (10 points) down to the inner core (100).
  3. Every answer works once. Use one twice across the six prompts and you get a use-after-free.
  4. The seventh prompt is root. A trivia question with one right answer, hidden in the nether and worth 100. Any answer counts there, even one you already used.

Every point is about 9 km of drilling. A perfect drill scores 700 and reaches 6,371 km, the center of the Earth.

About Code Drillion

I made Code Drillion for software engineers who’ve been told their knowledge doesn’t matter anymore. For a while, niche knowledge looked obsolete, first because of Google and lately because of LLMs. Now, knowing something on the fly gives you an edge over the slop-lords who have to ask their agents everything.

New to software engineering, love trivia, or in need of a mental refactor? Code Drillion plays a lot like Krillion, so almost any valid answer counts and you’ll score from your first drill. If you’re a more seasoned dev, the daily Code Drill lets you dust off your niche knowledge and beat the autocomplete.

A language model is built to produce the most probable next token. Ask one to name a sorting algorithm and you’ll hear quicksort, every time. That’s the autocomplete layer, and here it’s worth 10 points.

Everything below it comes from somewhere else: the outage you were paged for, the RFC you read for fun, the man page you actually finished, the codebase you inherited and came to understand. That knowledge still matters. It’s how you tell when generated code is wrong, and it’s what this game scores.

Answers are checked against a curated bank that keeps growing, and every answer carries a line of history. Rarity blends hand ranking with how often people look each answer up on Wikipedia.
